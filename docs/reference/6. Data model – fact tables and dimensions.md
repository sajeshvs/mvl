3. Data model – fact tables and dimensions

A procurement/star schema aligned with procurement data-model best practices: master data (suppliers, materials, projects, entities) plus transactional facts for quotations and POs.

Dimensions

DimDate

DateKey (YYYYMMDD, integer, PK)

FullDate (date)

Year, Quarter, MonthNumber, MonthName, WeekNumber

IsCurrentYear, IsLast12Months, etc.

DimEntity

EntityKey (PK)

EntityCode

EntityName

Region / Country (optional)

DimSupplierClient

PartnerKey (PK)

PartnerName

PartnerType (Supplier, Client)

PrimaryEntityKey (FK to DimEntity, optional)

Email, Phone

Rating (numeric or text)

DimProject

ProjectKey (PK)

ProjectCode

ProjectName

EntityKey (FK)

BusinessLine / Function (optional)

DimMaterial

MaterialKey (PK)

MaterialType

MaterialShortDescription (1-sentence)

Discipline

Category / Commodity (optional)

DimCurrency

CurrencyKey (PK)

CurrencyCode (USD, EUR, AED, etc.)

CurrencyName

ConversionRateToUSD (may be a separate FX fact; simplest is average or latest per period)

DimQuotationStatus

QuotationStatusKey (PK)

StatusName (Quotation, Waiting, Order, Cancelled)

IsWon (Order), IsOpen (Waiting, Quotation), IsLost (Cancelled)

DimPOType

POTypeKey (PK)

POTypeName (Base, Change Order)

DerivationRule (e.g., “EndsWith 1” vs “EndsWith 2”)


Fact tables

FactQuotationHeader

QuotationKey (PK, surrogate)

QuotationNumber (e.g., RFP-2025-000123)

QuotationType (IQ, RFQ)

EntityKey (FK)

PartnerKey (client or supplier, FK)

ProjectKey (FK)

MaterialKey (FK – dominant material type)

QuotationStatusKey (FK)

QuotationDateKey (FK to DimDate)

QuotationValue (original currency)

CurrencyKey

QuotationValueUSD (pre-converted)

CreatedByContact (responsible person name or ID)

FactPOTable (header-level)

POKey (PK)

PONumber (e.g., RFPO-2025-000123-1)

SourceQuotationKey (FK to FactQuotationHeader)

EntityKey (FK)

PartnerKey (supplier or client, FK)

ProjectKey (FK)

POTypeKey (Base, Change)

POPlacementDateKey (FK to DimDate)

POHeaderValue (header value in original currency)

CurrencyKey

POHeaderValueUSD

FactPOLine (optional but ideal)

POLineKey (PK)

POKey (FK)

LineNumber

MaterialKey (FK)

Quantity

UnitPrice

LineValue (original currency)

LineValueUSD

DeliveryTerms (text)

ForecastDeliveryDateKey (FK to DimDate)

If you need only header-level analysis now, FactPOTable is enough and can be later extended.
