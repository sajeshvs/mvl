4. Key DAX measures

Assume:

Date relationships:

FactQuotationHeader[QuotationDateKey] → DimDate[DateKey]

FactPOTable[POPlacementDateKey] → DimDate[DateKey]

Currency conversion already done into *_ValueUSD fields.

Below are core measures; names can be prefixed by “m_” in a dedicated Measure table.

text

-- Basic counts

Total Quotations :=

COUNTROWS ( FactQuotationHeader )


Total POs :=

COUNTROWS ( FactPOTable )


Total Base POs :=

CALCULATE (

[Total POs],

TREATAS ( { "Base" }, DimPOType[POTypeName] )

)


Total Change Orders :=

CALCULATE (

[Total POs],

TREATAS ( { "Change Order" }, DimPOType[POTypeName] )

)


Distinct Suppliers :=

DISTINCTCOUNT ( DimSupplierClient[PartnerKey] )


Distinct Projects :=

DISTINCTCOUNT ( DimProject[ProjectKey] )


-- Spend

Total Quotation Value (USD) :=

SUM ( FactQuotationHeader[QuotationValueUSD] )


Total PO Spend (USD) :=

SUM ( FactPOTable[POHeaderValueUSD] )


Total PO Spend (Last 6 Years) :=

VAR MaxYear =

MAX ( DimDate[Year] )

RETURN

CALCULATE (

[Total PO Spend (USD)],

DimDate[Year] >= MaxYear - 5      -- rolling 6-year window

)


-- Quote → Order conversion / Win-rate

Won Quotations :=

CALCULATE (

[Total Quotations],

TREATAS ( { "Order" }, DimQuotationStatus[StatusName] )

)


Open Quotations :=

CALCULATE (

[Total Quotations],

TREATAS ( { "Quotation", "Waiting" }, DimQuotationStatus[StatusName] )

)


Lost Quotations :=

CALCULATE (

[Total Quotations],

TREATAS ( { "Cancelled" }, DimQuotationStatus[StatusName] )

)


Win Rate % :=

DIVIDE (

[Won Quotations],

[Won Quotations] + [Lost Quotations]

)


Quote to PO Conversion % :=

DIVIDE (

[Total POs],

[Total Quotations]

)


-- Change-order share of spend

Change Order Spend (USD) :=

CALCULATE (

[Total PO Spend (USD)],

TREATAS ( { "Change Order" }, DimPOType[POTypeName] )

)


Change Order Spend % :=

DIVIDE ( [Change Order Spend (USD)], [Total PO Spend (USD)] )


-- Average PO value

Average PO Value (USD) :=

DIVIDE ( [Total PO Spend (USD)], [Total POs] )


-- Supplier ranking measures

Top Supplier Spend (USD) :=

[Total PO Spend (USD)]      -- used with a TopN filter in visual


Bottom Supplier Spend (USD) :=

[Total PO Spend (USD)]      -- with TopN + ascending sort


-- Time intelligence examples (requires proper DimDate)

Total PO Spend YTD :=

TOTALYTD (

[Total PO Spend (USD)],

DimDate[FullDate]

)


Total PO Spend PY :=

CALCULATE (

[Total PO Spend (USD)],

DATEADD ( DimDate[FullDate], -1, YEAR )

)


Spend Growth % :=

DIVIDE ( [Total PO Spend (USD)] - [Total PO Spend PY], [Total PO Spend PY] )

Win-rate formulas mirror standard opportunity win metrics, adjusted to your quotation statuses. Spend and ranking measures follow typical PO spend modeling patterns.
