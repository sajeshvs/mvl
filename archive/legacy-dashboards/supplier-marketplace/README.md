# MVL Supply Intel Hub - Supplier Marketplace Dashboard

## Overview
The Supplier Marketplace dashboard provides a comprehensive view of quotations, suppliers, and procurement activities across all MVL entities.

## Features

### Summary KPIs
- **Total Quotations**: Count of all quotation records
- **Total POs**: Count of purchase orders
- **Win Rate**: Percentage of quotations converted to orders
- **Total Spend (USD)**: Total PO value in USD

### Top Suppliers
Displays the top 15 suppliers ranked by total spend, allowing users to quickly identify key vendors.

### Quotation Funnel
Visual breakdown of quotation status:
- **Quotation**: Initial quote stage
- **Waiting**: Under review
- **Order**: Converted to PO
- **Cancelled**: Lost/cancelled quotes

### Materials by Discipline
Doughnut chart showing quotation value distribution across material categories.

### Marketplace Workbench
Interactive table displaying recent quotations with:
- Quote Number
- Type (RFQ/IQ)
- Status
- Project Name
- Material
- Value

## Filters
- **Entity**: Filter by MVL entity
- **Status**: Filter by quotation status
- **Material**: Filter by material category

## Data Source
Data is loaded from `data.json` which is generated by the `process_data.py` script from:
- Quotation reports (5 CSV files)
- PO list
- Client/Supplier list

## Technical Details
- **Framework**: Vanilla HTML/CSS/JavaScript
- **Charts**: Chart.js 4.4.0
- **Color Theme**: MVL Blue (#004578, #0078d4)
- **Data Format**: JSON

## Files
```
supplier-marketplace/
├── supplier-marketplace.html  # Dashboard HTML
├── data.json                  # Generated data file
└── resources/                 # Additional assets
```

## Usage
1. Ensure `data.json` is generated by running `process_data.py`
2. Open `supplier-marketplace.html` in a web browser
3. For local development, use a local server to avoid CORS issues:
   ```
   python -m http.server 8000
   ```
