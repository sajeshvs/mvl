# MVL Supply Intel Hub - Disciplines Consolidated Dashboard

## Overview
The Disciplines Consolidated dashboard provides budget vs actual analysis across all material disciplines, enabling project managers to track spending against quotation estimates.

## Features

### Overall Summary KPIs
- **Total Budget**: Sum of quotation values (proxy for budget)
- **Total Actual**: Sum of PO values (actual spend)
- **Total Variance**: Difference between budget and actual
- **Overall Utilization**: Percentage of budget spent

### By Entity Breakdown
Shows quotation value distribution across MVL entities:
- MVL International
- MVL Abu Dhabi
- MVL Dubai
- And other entities...

### Budget vs Actual Overview Chart
Bar chart comparing budget and actual spend for top disciplines, providing quick visual comparison.

### Disciplines Breakdown Grid
Card-based layout showing each material discipline with:
- **Discipline Name**: Material category code
- **Status Badge**: Under/On Track/Over/Critical
- **Budget**: Quotation value for the discipline
- **Actual**: PO value for the discipline
- **Utilization Progress Bar**: Visual indicator of budget utilization

### Utilization Thresholds
- **Under (Green)**: ≤80% utilization
- **On Track (Green)**: 81-100% utilization
- **Over (Orange)**: 101-120% utilization
- **Critical (Red)**: >120% utilization

## Data Calculation Logic

### Budget
Sourced from quotation values - represents the estimated cost at quotation stage.

### Actual
Sourced from PO values - represents the committed/actual spend.

### Variance
```
Variance = Budget - Actual
```
- Positive: Under budget
- Negative: Over budget

### Utilization
```
Utilization = (Actual / Budget) × 100%
```
