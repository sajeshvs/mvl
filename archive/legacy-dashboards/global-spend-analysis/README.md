# MVL Supply Intel Hub - Global Spend Analysis Dashboard

## Overview
The Global Spend Analysis dashboard provides executive-level visibility into procurement spending patterns, supplier performance, and PO type breakdown (Base vs Change Orders).

## Features

### Spend Summary KPIs
- **Total Spend (USD)**: Aggregate PO value converted to USD
- **Base PO Spend**: Value of initial purchase orders
- **Change Order Spend**: Value of change orders with percentage of total
- **Active Suppliers**: Count of unique suppliers with POs

### Top 10 Suppliers
Ranked list of highest-spend suppliers, enabling strategic vendor management.

### Base vs Change Order Comparison
Bar chart comparing:
- Total Base PO spend
- Total Change Order spend

This helps identify potential scope creep or project management issues.

### Spend by Material Category
Doughnut chart showing PO spend distribution by material discipline:
- Mechanical (M)
- Electrical (E)
- Architectural (A)
- Various (V)
- And more...

### Recent Purchase Orders
Interactive table showing recent POs with:
- PO Number
- Type (Base/Change Order)
- Supplier Name
- Value (USD)

## Filters
- **PO Type**: Filter by Base PO or Change Order
- **Material**: Filter by material category

## Business Rules Applied

### PO Type Identification
From Rita's email chain:
- `RFPO-xxx-xxx-1`: Base PO (last digit = 1)
- `RFPO-xxx-xxx-2+`: Change Order (last digit > 1)

### Material Code Extraction
Letter in PO number indicates material discipline:
- M = Mechanical
- E = Electrical
- A = Architectural
- V = Various
- And more (see DATA_MAPPING_RULES.md)

## Data Source
Data is loaded from `data.json` generated by `process_data.py` from:
- PO_List_Jan-23-2026.csv (3,539 POs)
- MVL_Clients_List_Jan-23-2026.csv (2,542 suppliers)

## Technical Details
- **Framework**: Vanilla HTML/CSS/JavaScript
- **Charts**: Chart.js 4.4.0
- **Color Theme**: MVL Orange (#c45500, #f5770a)
- **Data Format**: JSON
